Проверка веб-камеры онлайн

Нажмите кнопку включения камеры и разрешите доступ в появившемся запросе браузера. Если изображение появилось, камера передаёт видеопоток. Если экран остаётся пустым, проверьте физическую шторку камеры, системные разрешения, выбор устройства и не использует ли камеру другое приложение. Для работы камеры обычно требуется защищённое HTTPS-соединение. Отключите камеру после завершения теста.

Инструмент работает в браузере. Доступ к устройствам запрашивается только после вашего действия; поддержка отдельных функций зависит от браузера и операционной системы.

Как работает сайт?

Сервис «Девайсы» использует стандартные API браузера (HTML5, Web Audio API, WebRTC и Web Bluetooth / WebUSB там, где они поддерживаются) для диагностики прямо на устройстве. Доступ к камере, микрофону, USB и Bluetooth запрашивается только после вашего действия. Некоторые сведения о железе браузер не раскрывает.
