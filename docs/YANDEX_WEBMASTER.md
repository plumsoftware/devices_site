# Настройка девлаб.рф в Яндекс Вебмастере

Инструкция для обновлённой версии сайта с отдельными URL страниц проверок.

## 1. Добавить и подтвердить сайт

1. Откройте [Яндекс Вебмастер](https://webmaster.yandex.ru/).
2. Добавьте сайт с основным адресом **https://девлаб.рф/** (HTTPS, без `www`).
3. Подтвердите права удобным способом. Для статического сайта обычно удобно загрузить HTML-файл подтверждения в корневую папку сайта или добавить предложенную Яндексом мета-тегу в `<head>` главной страницы. Используйте именно значение, которое покажет ваш аккаунт Вебмастера.
4. Если Яндекс выдаст файл подтверждения, положите его в корень сайта рядом с `index.html` и не переименовывайте.

## 2. Отправить Sitemap

В меню Вебмастера откройте **Индексирование → Файлы Sitemap** и добавьте:

`https://девлаб.рф/sitemap.xml`

После публикации проверьте, что Sitemap успешно загружен и в нём нет ошибок. Файл содержит главную страницу и отдельные страницы инструментов. В XML домен записан в технической IDN-форме (`xn--80acbhf1b.xn--p1ai`); это тот же самый домен `девлаб.рф`.

## 3. Проверить robots.txt

Откройте в браузере:

`https://девлаб.рф/robots.txt`

В нём должна быть строка:

```text
User-agent: *
Allow: /
Sitemap: https://девлаб.рф/sitemap.xml
```

Также проверьте доступность Sitemap по адресу `https://девлаб.рф/sitemap.xml`.

## 4. Проверить страницы и отправить на переобход

В инструменте **Проверка URL** проверьте главную и страницы:

- `https://девлаб.рф/keyboard-test/`
- `https://девлаб.рф/mouse-test/`
- `https://девлаб.рф/speakers-test/`
- `https://девлаб.рф/headphones-test/`
- `https://девлаб.рф/microphone-test/`
- `https://девлаб.рф/camera-test/`
- `https://девлаб.рф/screen-test/`
- `https://девлаб.рф/usb-test/`
- `https://девлаб.рф/wifi-test/`
- `https://девлаб.рф/bluetooth-test/`
- `https://девлаб.рф/system-test/`
- `https://девлаб.рф/more-tests/`

Убедитесь, что страницы доступны роботу, возвращают HTTP 200, не закрыты от индексирования и имеют правильный canonical на собственный URL. После проверки можно запросить переобход важных URL. Переобход не гарантирует включение страницы в поиск или определённую позицию.

## 5. Проверить диагностику сайта

Откройте раздел **Диагностика сайта** и устраните критические ошибки, если они появятся. После публикации изменений повторно проверьте Sitemap и несколько URL.

## 6. Как подтвердить, что всё работает

- В Вебмастере Sitemap обработан без ошибок.
- Проверка URL видит код ответа 200 и разрешённое индексирование.
- В браузере открываются все URL с завершающим `/`.
- В исходном коде каждой страницы есть свой `<title>`, `description` и canonical.
- Через некоторое время в отчётах индексирования появляются обработанные страницы.

**Важно:** добавление сайта и отправка Sitemap не гарантируют моментальную индексацию или высокие позиции. Яндекс самостоятельно принимает решение о включении страниц в поиск.

## 7. После каждого нового инструмента

Если добавите новую индексируемую страницу, внесите её URL в `sitemap.xml`, добавьте внутреннюю ссылку на неё в навигационный список на страницах сайта и проверьте URL в Вебмастере.

Официальный сервис: [webmaster.yandex.ru](https://webmaster.yandex.ru/).
