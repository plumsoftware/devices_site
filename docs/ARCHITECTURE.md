# Архитектура и ограничения диагностики

Проект — статический сайт без собственного backend. HTML находится в `index.html`, стили — в `style.css`, функциональность — в `app.js`, реклама — в `ads.js` и `ads-config.js`, изображения — в `assets/`.

## Модули

1. **Клавиатура:** события `keydown` / `keyup` и `KeyboardEvent.code`, подсветка и счётчик уникальных клавиш.
2. **Мышь:** события мыши и `wheel`; сбор статистики включён только на странице проверки мыши.
3. **Аудиовыход:** генерация тестового тона через `AudioContext` и `StereoPannerNode`.
4. **Микрофон:** `getUserMedia({ audio: true })` + `AnalyserNode`; поток останавливается при выключении.
5. **Камера:** `getUserMedia({ video: true })`; поток останавливается при выключении.
6. **Экран:** полноэкранные RGB/монохромные заливки; `Esc` завершает тест.
7. **Система:** только значения, которые браузер действительно предоставляет. UA Client Hints используются при наличии.
8. **Интернет:** `navigator.onLine`, `navigator.connection` (не во всех браузерах) и 3 запроса к публичному статическому ресурсу. Измерение является приблизительным временем загрузки ресурса, а не полноценным speed test.
9. **USB / Bluetooth:** WebUSB и Web Bluetooth предоставляют доступ только к выбранному пользователем устройству. Это не сканер всех физических портов/устройств. Обычно нужны Chromium-браузер, HTTPS и пользовательское разрешение.
10. **Дополнительно:** `navigator.getBattery()` и `navigator.storage.estimate()` при поддержке браузером.

## Ограничения браузера

Страница не может достоверно перечислить все подключённые USB/Bluetooth-устройства, определить неисправные физические порты, прочитать температуру/частоту CPU, точный объём ОЗУ или внутренние системные ошибки. Для таких проверок нужно нативное приложение с системными разрешениями. Интерфейс не показывает фиктивные значения там, где браузер не предоставляет данные.

## Языки и тема

Тексты RU/EN находятся в словаре `translations` в `app.js`. Язык сохраняется в `localStorage` ключом `devices-language`, тема — `devices-theme`.
