# Подключение рекламы Яндекс РСЯ

В проект добавлена веб-интеграция Рекламной сети Яндекса:

- **Баннер** — закреплён внизу окна браузера и остаётся на виду при прокрутке. На узких экранах занимает всю ширину; основной контент получает нижний отступ, поэтому баннер его не перекрывает.
- **Полноэкранная реклама** — запрашивается после нескольких переходов между разделами; вызов не происходит при первой загрузке сайта. Частота дополнительно ограничена кодом: не чаще одного вызова за 5 минут. Настройте frequency cap блока в кабинете РСЯ как второй уровень ограничения.

## Где указать настоящие ID

Откройте файл `ads-config.js` в корне проекта:

```js
window.DEVICES_ADS_CONFIG = {
    enabled: true,
    bannerBlockId: 'R-A-ВАШ_ID_БАННЕРА',
    fullscreenBlockId: 'R-A-ВАШ_ID_ПОЛНОЭКРАННОГО_БЛОКА',
    fullscreenEveryNavigations: 3
};
```

Замените примеры `R-A-...` на реальные ID из кабинета РСЯ. В архиве реальные ID оставлены пустыми, чтобы не подставлять выдуманные значения. После добавления ID установите `enabled: true`.

### Какие блоки создать в кабинете РСЯ

1. Добавьте и подтвердите сайт в РСЯ, дождитесь модерации.
2. Создайте блок типа **Баннер** и скопируйте его ID в `bannerBlockId`.
3. Создайте блок типа **Полноэкранный** и скопируйте его ID в `fullscreenBlockId`.
4. Установите `enabled: true` и загрузите сайт на HTTPS-домен.

Используйте ID веб-блоков, созданных для сайта в РСЯ. ID мобильного SDK из Android/iOS-приложения не следует автоматически переносить в веб-проект.

## Как работает интеграция

- `ads-config.js` — единственное место для ID, включения рекламы и частоты межстраничного показа.
- `ads.js` — загружает `https://yandex.ru/ads/system/context.js`, выводит баннер и запрашивает полноэкранную рекламу.
- `index.html` содержит контейнер `#yandexBannerSlot`; `style.css` закрепляет его внизу окна браузера.
- Для полноэкранной рекламы используется один `fullscreenBlockId`; значение `platform` определяется автоматически через `Ya.Context.AdvManager.getPlatform()`.
- По умолчанию полноэкранная реклама запрашивается после каждых трёх переходов между диагностическими разделами, но не чаще раза в пять минут.

Проверьте показы на опубликованном HTTPS-домене и в браузере без блокировщиков рекламы. В предпросмотре или локальной среде выдача рекламы может быть ограничена настройками площадки и модерацией.
