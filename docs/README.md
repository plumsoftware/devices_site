# Devices — онлайн-диагностика устройств

Статический сайт для проверки периферии и браузерных возможностей. Интерфейс доступен на русском и английском языках; выбранный язык и тема сохраняются в браузере.

## Возможности

- Клавиатура: подсветка нажатых клавиш и прогресс.
- Мышь: кнопки и направление прокрутки; счётчики работают только на странице теста мыши.
- Динамики и наушники: раздельное воспроизведение левого/правого канала через Web Audio API.
- Микрофон и камера: запрос разрешения только после нажатия кнопки.
- Экран: полноэкранная заливка цветами, выход по `Esc`.
- Система: сведения, доступные браузеру (платформа, браузер, CPU cores, разрешение экрана, язык и сеть).
- Интернет: онлайн-статус, Network Information API при наличии и ориентировочное время загрузки тестового ресурса.
- USB и Bluetooth: проверка поддержки API и выбор совместимого устройства через системный диалог браузера.
- Дополнительная диагностика: доступность API, батарея и оценка браузерного хранилища, если браузер раскрывает эти данные.
- Реклама РСЯ: закреплённый нижний баннер и полноэкранный блок при переходах между разделами.

## Быстрый запуск

Сайт статический, поэтому можно открыть `index.html` напрямую для просмотра интерфейса. Для тестов камеры, микрофона, USB и Bluetooth используйте HTTPS или `localhost`.

При наличии Node.js:

```bash
npm install
npm start
```

Затем откройте `http://localhost:3000`.
