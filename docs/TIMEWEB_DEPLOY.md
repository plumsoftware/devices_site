# Инструкция по развертыванию на Timeweb Cloud

Этот проект представляет собой **статический сайт** (HTML5 + Tailwind CSS + JavaScript без серверной бэкенд-части на Node.js/Python), поэтому его развертывание на Timeweb Cloud выполняется максимально просто и быстро.

## Вариант 1: Развертывание через Панель управления Timeweb Cloud (Файловый менеджер / FTP)

1. **Создайте сайт в панели Timeweb:**
   - Войдите в личный кабинет [Timeweb Cloud](https://timeweb.cloud/).
   - Перейдите в раздел **«Веб-сервер»** → **«Сайты»** → **«Создать сайт»** (или добавьте домен).
   - Выберите тип сайта: **Статический сайт** (без CMS).

2. **Соберите архив для загрузки:**
   - Запакуйте все файлы проекта (`index.html`, `style.css`, `app.js`, `ads.js`, `ads-config.js`, папку `assets/`, `favicon.ico`, `favicon.png`, `apple-touch-icon.png`) в ZIP-архив (или используйте готовый архив `devices_site_ready.zip`).

3. **Загрузите файлы на хостинг:**
   - Откройте корневую папку вашего сайта в панели Timeweb (обычно `/public_html` или `/www/ домен.ru`).
   - Загрузите и распакуйте ZIP-архив прямо в корневую директорию.
   - Убедитесь, что файл `index.html` находится в самом корне папки `public_html`.

## Вариант 2: Загрузка через SSH / SFTP

Если вы используете VPS/VDS на Timeweb Cloud с установленным Nginx или Apache:

1. Подключитесь по SSH:
   ```bash
   ssh root@ваш_ip_адрес
   ```
2. Клонируйте репозиторий или распакуйте архив в директорию веб-сервера (например, `/var/www/html`):
   ```bash
   cd /var/www/html
   unzip devices_site_ready.zip
   ```
3. Установите права доступа:
   ```bash
   chown -R www-data:www-data /var/www/html
   chmod -R 755 /var/www/html
   ```
4. Сайт готов к работе и доступен по вашему домену!


Перед публикацией настройте ID рекламы в `ads-config.js` (см. [ADS_YANDEX.md](ADS_YANDEX.md)). Для проверки камеры, микрофона, USB и Bluetooth используйте HTTPS.
